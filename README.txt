Plus1me - static HTML website
=============================
Plain HTML/CSS, no PHP or WordPress needed.

Pages: index.html (Home), about.html, contact.html, help.html, age-policy.html
Assets: css/webflow-style.css, images/

To publish: upload everything in this folder to any web host
(Netlify, GitHub Pages, Cloudflare Pages, or your current host's public_html).
To preview locally: just double-click index.html.

To edit: open the .html file in a text editor. The navigation menu is
repeated at the top of each page, so update it in all 5 files.
